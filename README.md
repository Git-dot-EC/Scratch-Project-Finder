# Scratch Project Finder
Scratch Project Finder is a booklet shortcut used to find projects through their ID or just by searching a name! (Is it useful? I don't know. I just wanted to make something-)

# How to get Scratch Project Finder
To add Scratch Project Finder to your browser, just copy this down into a new bookmark's URL and press save:

**javascript:(()=>{const s=document.createElement("script");s.src="https://git-dot-ec.github.io/Scratch-Project-Finder/project-finder.js?t="+Date.now();document.body.appendChild(s)})()**
